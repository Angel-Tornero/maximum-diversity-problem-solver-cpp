# Maximum Diversity Problem Solver - C++ (University Project)

## 📝 Description

This project implements a solver for the **Maximum Diversity Problem** (MDP) in C++.  
It explores various heuristic and metaheuristic approaches to maximize the diversity of selected subsets from a larger set of elements.

The program was developed during a university course and includes basic benchmark files for testing.

---

### 🔧 How to Run

To execute the program, compile and run the main file:

```bash
./main
```

The program will automatically evaluate the following problem instances from the problems/ folder:

- max_div_15_2.txt
- max_div_20_2.txt
- max_div_30_2.txt

- max_div_15_3.txt
- max_div_20_3.txt
- max_div_30_3.txt

For each instance, it evaluates multiple values of m and prints a results table to the console, including the solution diversity, elements selected, CPU time, and number of nodes generated.

---

## 📊 Statistics

The `stats/` directory contains CSV files with the output results of different algorithms. You can check this files to compare execution times, solution quality, and other metrics.
